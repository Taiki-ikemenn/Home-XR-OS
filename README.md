# Home XR OS

ブラウザで動く XR（VR/AR）風ホーム。指カーソルでつまんで操作します。

- 公開ページ：https://taiki-ikemenn.github.io/Home-XR-OS/
- `index.html` … いちばん新しいバージョン
- `versions.json` … バージョンの一覧（設定 → アップデート で使います）
- `versions/<番号>/index.html` … ダウングレード用の過去のバージョン
- `firestore.rules` … チャット・フィード・いっしょの部屋用の Firestore ルール（xr_users / xr_posts / xr_rooms / xr_spaces）
